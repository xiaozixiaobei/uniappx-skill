# uniappx-skill

面向 AI 编程助手的 uni-app x 开发技能，帮助助手理解项目结构、遵循 UTS 与跨平台开发约束，并更稳妥地完成代码编写、排查和评审。

## 内容

- [`SKILL.md`](./SKILL.md)：技能说明与开发指引。

## 使用

将本仓库作为技能来源，按你所使用的 AI 编程工具的技能安装方式接入。使用前请确认工具支持 `SKILL.md` 格式，并根据项目实际情况补充对应平台和框架版本信息。

## 贡献

欢迎提交 Issue 或 Pull Request。新增开发指引时，请优先保持内容准确、可验证，并注明适用的平台或版本；平台能力存在差异时，应明确说明，不要假设所有端的行为一致。
